# Jessica Hung — personal website

A responsive, accessible static portfolio based on Yu-An (Jessica) Hung's resume. No build tools or dependencies are required. About, Experience, and Projects tabs support keyboard navigation; all content stays visible if JavaScript is disabled. Uses system fonts.

## Preview
Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.

## Publish on GitHub Pages
1. Copy `index.html`, `style.css`, `script.js`, and `.nojekyll` into the root of your cloned repository.
2. Commit and push these files to `main`.
3. On GitHub, open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**. Select `main`, choose `/ (root)`, and save.
5. GitHub will display the published URL when deployment completes. A repository named `YOUR-USERNAME.github.io` is served at `https://YOUR-USERNAME.github.io/`. Other repository names are served beneath `/REPOSITORY-NAME/`.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
